# Lambrecht & Procoppo · Gestión Jurídica

Aplicación web demostrativa para la gestión integral de un estudio jurídico de Río Negro.

## Funcionalidades

- Escritorio con agenda, vencimientos e indicadores
- Calendario judicial
- Gestión de clientes y causas
- Tablero de tareas
- Biblioteca documental
- Equipo y responsables
- Presupuestos y honorarios
- Consulta de movimientos de Mi PUMA
- Escritos asistidos por IA
- Transcripciones de audiencias y reuniones
- Copilot jurídico contextual
- Configuración profesional y centro de soporte

## Tecnologías

- Angular 20
- TypeScript
- CSS responsivo
- GitHub Actions y GitHub Pages

## Ejecutar localmente

```bash
npm install
npm run build
npx ng serve
```

La cuenta demostrativa puede abrirse desde el botón **Explorar cuenta demo**.

## Alcance

La versión incluida funciona como demostración frontend con datos ficticios. La autenticación productiva, persistencia, servicios de IA e integración real con PUMA deben conectarse mediante un backend Java y Spring Boot.
